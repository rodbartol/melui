# Melui

Plain CSS. Depth, material, symbols.

## Use

```html
<link rel="stylesheet" href="melui/dist/melui.css" />
```

## Theme

A theme is your CI: colours and font. Load it after Melui.

```html
<link rel="stylesheet" href="melui/dist/themes/mono.css" />
<html data-ui-theme="mono"></html>
```

Samples: `japan-fish`, `mono`, `loud`.

## Build

```bash
npm run build
```

Output goes to `dist/`. The docs site is `dist/site/`.
